## LexScore v0.7.0 — 评分模型重做（校准驱动）

这一版没有加新功能，而是解决一个**比功能更致命的问题**：

> 旧版引擎**区分不了好作文和差作文**。

### 问题是怎么发现的

按「用真实分段的作文验证评分一致性」这个思路，我建了一份校准语料
（`lib/calibration/corpus.ts`），收录 8 篇按官方 band descriptor 撰写的作文，
覆盖雅思大作文 / 小作文、托福综合写作，每篇都标注了人工作出的目标分段。

第一次跑的结果：

| 作文 | 目标 | 旧引擎 |
| --- | --- | --- |
| Band 4.5（106 词，只有断言） | 4.5 | **6.0** |
| Band 5.5（模板密集） | 5.5 | **6.0** |
| Band 6.5 | 6.5 | 6.5 |
| Band 8.0（论证严谨、词汇精确） | 8.0 | **6.5** |

**全部挤在 6.0–6.5，跨度只有 0.5 档。**

### 两个指标在惩罚好作文

进一步用 `scripts/metrics-audit.ts` dump 出所有客观指标，找到了根因：

| 指标 | Band 4.5 | Band 8.0 | 问题 |
| --- | --- | --- | --- |
| 句长标准差 | 3.6 | 7.5 | ✅ 最好的区分指标 |
| 词汇多样度 | 0.564 | 0.839 | ✅ 单调 |
| 复合句占比 | 31% | 75% | ✅ 单调 |
| **扣题度** | 47 | **47** | ❌ 完全无区分 |
| **衔接密度** | 0.85 | **0.44** | ❌ **越写得好越低** |

- **扣题度用字面关键词匹配**。高分作文必然做同义替换
  （`university` → `tertiary education`，`free` → `funded by the state`），
  字面命中反而更低。**这个指标在惩罚词汇能力。**
- **衔接密度惩罚隐性衔接**。母语级写作靠指代、平行结构、主位推进，
  本来就不需要满篇 `Firstly / Moreover`。

### 重做后的模型

评分从「基准分 + 零散加减」改为**指标合成**：每个维度由若干可测量指标加权，
指标用分段线性锚点归一化后映射到官方量表。锚点数值全部来自校准语料的实测。

关键修正：

1. **扣题度改为话题域匹配** —— 只要作文落在同一话题域内就算扣题。
   字面命中率不再直接决定分数。
2. **衔接密度不再越高越好** —— 改成看衔接手段的多样性（且先扣掉模板化衔接）
   与**段落开头是否机械化**。这是区分「组织能力强」与「套模板」最直接的形式特征：
   Band 5.5 五段全部以 `With the rapid development / Firstly / Secondly /
   On the other hand / In a word` 开头；Band 8 只有 1/5。
3. **跑题句比例从评分中移除** —— 它同样基于字面匹配，不可靠。
   保留为界面提示，不再影响分数。
4. **按题型分开评分** —— 雅思小作文考的是 Task Achievement（有没有 Overview、
   数据覆盖全不全），不设立场要求；托福综合写作考听力还原度。
   用同一套指标打所有题型，是小作文长期被误判的根因。
5. **论证深度** —— 用因果链、让步反驳、限定语等**可正则检测**的形式特征
   衡量论证方式，区分「有话说」和「说透」。
   刻意剔除了 `because` —— 弱作文反而高频滥用它。
6. **论证展开度按词数而非句子数** —— 高分作文句子更长、信息密度更高，
   按句子数衡量会反过来惩罚它。
7. **字数不达标施加全局惩罚** —— 官方明确把篇幅不足列为扣分依据，
   这个缺陷会同时体现在四个维度上。

### 新增的可复现工具

校准不是一次性的，这三个脚本都留在仓库里，纳入 `npm run verify`：

- `npm run verify:calibration` —— 跑完整校准，任何一项不通过就以非 0 退出码结束
- `npm run audit:metrics` —— dump 所有客观指标，检查哪些真能区分档次
- `npm run score:debug [样本]` —— 打印单个样本每个维度的指标原始值、归一化结果与权重

以后再有人说「分数不对」，先跑这三个，而不是拍脑袋改参数。

### 已知局限（诚实说明）

- **人工标注本身有 ±0.5 档不确定性**。同一篇作文不同考官也会差半档，
  所以校准目标是「全部落在 ±1 档内、平均不超过 0.5 档」，不是逐篇精确命中。
- **规则引擎只能测形式特征**。「这个论证有没有说服力」这类语义判断，
  它给不出可靠答案 —— 这也是 LLM 增强路径仍然需要的原因。
- **托福综合写作偏低约 0.7 档**。语料只有 2 篇，样本量不足以判定是系统性偏差
  还是标注本身偏乐观，需要更多真实作文来验证。
