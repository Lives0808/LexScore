## LexScore v0.3.1 — 开源协议与统一徽章

这一版是**文档与元数据更新**：评分引擎、界面和安卓 App 均无功能变化。

### 变更

- **正式补上 MIT 开源协议**（[`LICENSE`](../LICENSE)）。此前 README 写的是
  「私有项目，暂未开源授权」，从本版起 LexScore 以 MIT 协议开源，
  可自由使用、修改和分发。
- **README 徽章统一**：顶部加入版本 / 协议 / 技术栈徽章，
  与作者主页其他项目的视觉风格一致。
- **仓库元数据统一**：About 改为「一句话定位」，并补齐 Topics 标签。

### 下载

附件 `LexScore-0.3.1.apk` 与 v0.3.0 功能完全一致，可按需下载；
已安装 0.3.0 的用户无需更新。

**兼容性**：Android 7.0 及以上（minSdk 24），targetSdk 36。
签名与前几版一致，可直接覆盖安装。
