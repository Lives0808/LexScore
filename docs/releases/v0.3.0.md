## LexScore v0.3.0 — 安卓原生应用

这一版把 LexScore 做成了**可以直接安装到安卓手机上的 App**，
并且**完全离线可用**——不需要服务器，不需要联网，不需要任何 API Key。

### 安卓 App

下载附件 `LexScore-0.3.0-release.apk`（3.3 MB），在手机上安装即可。
首次安装需要允许「安装未知来源应用」，部分机型会提示风险 —— 这是因为 APK
用的是仓库内自签名证书，不是从应用商店安装的。

- **离线批改**：整套评分引擎跑在 App 内部，飞行模式下也能批改
- **无需登录**：没有账号体系，打开就能用
- **数据留在本机**：作文与语料库存在设备本地，不上传任何内容
- 自适应图标、启动图、主题色都已配置

App 里跑的是**同一份引擎、同一套界面代码**，所以批改结果与网页版逐字节一致，
不存在「两套实现各算各的」问题。

**兼容性**：Android 7.0 及以上（minSdk 24），targetSdk 36。

**验证结果**：

### 架构变更：改为静态导出

为了能打包进 App 并离线运行，应用从「Next.js 服务端渲染」改为**静态导出**：

```
Next.js 静态导出（out/）
      ↓  npx cap sync android
安卓工程 assets/public/
      ↓  ./gradlew assembleRelease
LexScore-0.3.0-release.apk
```

副作用与取舍（都写进了 README）：

- **不再需要后端**，因此部署到任意静态托管也变简单了
- **模型评分器在客户端不再启用**。API Key 放在客户端会被任何人从 APK 里解出来，
  所以浏览器与安卓端一律使用规则评分器。想启用模型需要起一个独立后端，
  或改成「用户自带 Key」模式——代码都保留着。
- 批改接口 `app/api/grade/route.ts` 已删除，改为 `lib/grade-client.ts` 直接调用引擎
  （动态 import，首屏只加载表单，点「开始批改」时才加载引擎）

### 其他变更

- 报告页从 `/report/[id]` 改为 `/report?id=xxx`。
  静态导出要求动态路由提供 `generateStaticParams`，而报告存在浏览器的
  localStorage 里、构建时无法枚举，查询参数方案对静态托管和 WebView 都更可靠。
- 图标生成脚本扩展为**一套代码生成 Web / PWA / 安卓全套资源**：
  21 个文件，包括五种密度的 `ic_launcher` / `ic_launcher_round` /
  `ic_launcher_foreground`（自适应图标前景按 66dp 安全区缩放）以及启动图。
  依然是手写 PNG chunk + zlib，4× 超采样抗锯齿，零图形库依赖。
- 新增 `scripts/build-android.sh`：自动定位 JDK 与 Android SDK，
  一键完成「静态导出 → Capacitor 同步 → Gradle 打包」。
- ESLint / Prettier 排除 `android/`（Capacitor 会把 Web 产物同步进去）。

### 环境要求

- **JDK 21**（Capacitor 8 要求 Java 21 编译目标）
- **Android SDK**：platform 36 + build-tools
- 构建：`npm run android:apk`，产物在 `android/app/build/outputs/apk/release/`

### 关于签名

APK 使用仓库内 `android/keystore/lexscore-release.jks` 自签名，
配置在 `android/keystore.properties`。这是**内部测试分发**的密钥，
提交进仓库是为了保证后续版本能覆盖升级（Android 要求签名一致）。

**如果要上架任何应用商店，请务必替换为你自己的密钥，并把密钥移出仓库。**

### 已知限制

- 只有安卓版，没有 iOS 版（需要 macOS + Xcode）
- 数据存在设备本地，清除应用数据会丢失，没有云同步
- APK 未做代码混淆（`minifyEnabled false`），体积偏大但便于排查问题
- 批改结果不等同于官方考试成绩，定位是备考训练与自我诊断工具

### 快速开始（开发）

```bash
npm install
npm run dev           # 网页版，http://localhost:3000
npm run android:apk   # 构建安卓 APK
npm run verify        # 引擎层 + 界面层校验
```
