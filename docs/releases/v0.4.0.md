## LexScore v0.4.0 — 可视化、深色模式、离线可用

这一版把「能批改」升级成「看得懂、留得住」。

### 四维评分雷达图

把四个维度的得分画成雷达图，并叠加一条 Band 6.0 / 3.0 参考虚线。
**落在虚线内的维度就是当前短板**，一眼看出来，不用读文字。
纯 SVG 实现，无图表库依赖。

### 分数变化曲线

语料库页面新增总分走势图：画出历次批改的总分，标注每篇的分数与首尾变化幅度。
**进步可见是留存的关键** —— 用户看到线在往上走，才会继续写下一篇。

### 深色模式

跟随系统设置自动切换。所有颜色都走 CSS 变量，深色模式只覆盖一遍变量值；
实心按钮单独用 `--color-accent-solid`，避免深色下按钮对比度不足。

### PDF 导出

报告页新增「导出 PDF」，走浏览器打印。
打印样式强制切回浅色（否则深色模式会把整页喷成黑底），
并自动隐藏导航、按钮、筛选器等交互元素，展开折叠的评分依据。

### PWA 离线

Service Worker 采用 stale-while-revalidate：有缓存先返回缓存并后台更新。
因为整个应用是静态导出、引擎跑在客户端，**只要访问过一次，断网也能完整批改**。
安卓 App 内不注册 Service Worker（资源本来就在本地，反而会在更新版本后提供旧资源）。

### README 重写

按「功能 + 价值」四块组织：四维对齐批改 / 深度逻辑诊断 / 反模板化检测 / 个人语料沉淀，
并补上竞品对比表、分用户的一分钟快速开始、以及分「已完成 / 进行中 / 计划中」的路线图。

### 校验增强

`verify:ui` 新增雷达图与走势图的渲染断言（SVG、得分多边形、轴标签、分数、
以及「只有一篇记录时不应渲染走势图」）。

### 版本号说明

v0.3.1 已占用 Android `versionCode 4`，因此本次为 `versionCode 5`。
签名与前几版一致，可直接覆盖安装。

### 快速开始

```bash
npm install
npm run dev      # http://localhost:3000
npm run verify   # 引擎层 + 界面层 + 产物层
```

安卓 APK 见 [v0.3.0 release](https://github.com/Lives0808/LexScore/releases/tag/v0.3.0)，
或本地执行 `npm run android:apk` 重新构建。

### 说明

- 网页版的「导出 PDF」依赖浏览器打印；安卓 App 内暂不支持打印
- 离线能力需要**至少访问过一次**，首次访问仍需联网
